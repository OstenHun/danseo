# 성능 과장 회귀 검증

요약: 관계 HTML의 성능 비교에 원문 표와 필드별 검토를 요구한다. 실제 Argon의 CRAG 일반화는 출력 전에 차단되고, 조건별 예외를 담은 결과는 통과했다. 원문 의미 전체와 에이전트의 분류 정확성은 자동 인증하지 않는다.

## 변경

기존 개요·수량 검사에 [표 조건·예외 검사](../skills/danseo/references/performance-verification.md)를 연결했다. 새 생성은 evidence v2를 사용한다. 이전 v1 evidence나 미해결·누락·낡은 검토는 다시 작성해야 하며 기존 HTML은 수정하지 않는다. UI 자산과 데스크톱 기본 검수 정책은 유지한다.

대상은 화면 제목·짧은 논문 이름·주제, 논문 노트·연결 주장·조건·한계·현재 검토 이유/범위(stale 이력 제외), 관계 이유, 출처 확인 범위다. 각 필드의 현재 해시와 분류를 요구한다. 성능 비교는 원문 페이지의 연속 표 블록에서 숫자를 읽고 같은 조건의 전체 열을 계산한다. 정확한 행 라벨·지표 방향·각주를 보존하며 결측을 0으로 바꾸지 않는다. 계산된 범위·우세·동률·열세·미보고 문장만 출력에 허용한다.

## 실제 오류 — 2026-11-16

이전 Argon이 작성한 12편 RAG 후보와 CRAG 제공판 PDF를 원본 그대로 보존했다. [CRAG 논문](https://arxiv.org/abs/2401.15884)의 제공판 PDF p.7 Table 1을 이미지로 읽고 페이지 추출문과 대조했다. 재현 표시 `Self-RAG*`와 원문 인용 결과도 구분했다.

| 확인 | 결과 |
| --- | --- |
| 최초 12편 후보 + 예전 빈 수량 evidence | 성능 필드 검토 누락으로 HTML 저장 차단 |
| 원래 “두 생성기 모두 일관되게 능가” 문장 + 표 evidence | 원문에서 계산한 문장과 달라 차단 |
| 같은 표에 모든 비교 우세 주장 | 열세 2건을 명시하며 차단 |
| 성능 문장을 non-performance로 면제 | 비교 표현 탐지로 차단 |
| 예외가 있는 열 생략 / Accuracy 방향 뒤집기 | 표 정합성 / 지표 방향 오류로 차단 |
| 범위·예외를 보존한 교정 후보 | 생성 통과, source_semantics는 not-certified 유지 |

Self-CRAG와 Self-RAG를 두 생성기·네 지표에서 비교하면 8개 셀 중 6개가 우세하고 2개는 열세다. LLaMA2-hf-7b의 PubHealth는 0.6 대 0.7, SelfRAG-LLaMA2-7b의 ARC는 67.2 대 67.3이다. 따라서 모든 조건의 일관된 우월 주장은 성립하지 않는다. 이 비교는 통계적 유의성을 주장하지 않는다.

교정 통과는 해당 두 논문의 파생 회귀 후보에 한정한다. 원래 12편의 모든 관계를 다시 검증하거나 Argon을 새로 호출한 결과가 아니다. 원래 후보·PDF·로그·캡처는 로컬에 보존하며 공개 테스트는 명시적인 합성 표를 사용한다.

## 검증 경계

논문 작성자의 주장을 그대로 인용했다고 검증된 성능 결론이 되지는 않는다. 원문 전사, 표 블록 경계, 의미 있는 비교 범위, 성능/비성능 분류는 계속 원문 대조가 필요하다. 알려진 표현 탐지와 완전한 필드 목록은 임의 자연어의 완전한 판별기가 아니다. 지원하지 않는 복잡한 표는 수치를 추측해 단순화하지 않고 미확인으로 남긴다.

검증 명령은 `npm test`, `npm run test:package`, `npm run check:docs`다. 합성 회귀는 두 성능 예외·동률·결측·지표 방향·열 누락·원문 변조·조건/각주 이름·근거 연결·stale 검토와 출력 차단을 다룬다. 실제 자료 회귀와 별도로 수행하며 사용자 이해나 연구 재현의 인증으로 보고하지 않는다.

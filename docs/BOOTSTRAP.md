# 초기 구성 기록

요약: 논문 공통 기록과 프로젝트 적용 판단을 분리하는 파일 기반 MVP로 시작했다. 이 문서는 초기 구성의 요약이며 현재 기능·검증 상태는 CLI·TASKS·공개 준비 기록을 따른다.

작성·정리: 2026-10-21 KST / PTP-BOOTSTRAP-001.

## 초기 선택

연구 비교와 제약이 있는 실험 작업에서 같은 카드 형식이 통하는지 확인하기 위해 독립 코드·schema·skill·합성 예제 공간을 만들었다. 개인 프로젝트의 원본은 기존 위치에 보존하고 제품 저장소에 복제하지 않았다.

초기 작업명은 paper-to-project였고 현재 제품·패키지·CLI 이름은 Danseo / danseo다. 이름의 기준은 [명칭 결정](NAMING.md)이 소유한다.

## 현재 상태로 이어지는 문서

- [PRD](PRD.md): 제품 방향과 후속 범위.
- [CLI 구현](CLI_IMPLEMENTATION.md): 구현한 읽기·검사·내보내기.
- [TASKS](../TASKS.md): 안정 작업 ID와 현재 완료 조건.
- [공개 준비](OPEN_SOURCE.md): 비공개 GitHub와 실제 CI·설치 검사.

초기 폴더·문서 구성만으로 앱 완성, 연구 재현이나 사용 효과를 확인한 것으로 처리하지 않는다. 자세한 개인 작업 기록은 로컬에 보존하며 공개 재현 자료는 합성 예제와 테스트다.
